# PHASE 3 — 링크프라이스 광고 적용

> **선행 조건:** PHASE 1 도메인 교체 완료 후 진행

---

## Step 1 — 링크프라이스 가입 및 사이트 등록

1. [linkprice.com](https://linkprice.com) → 퍼블리셔 회원가입
2. 사이트 등록 신청 → 커스텀 도메인으로 입력
3. 심사 승인 대기: **1~3 영업일**

---

## Step 2 — 광고주 선정 (우선순위)

| 순위 | 카테고리 | 단가 | 선정 이유 |
|------|---------|------|---------|
| 1순위 | 금융 (증권사, 투자 앱) | 5,000~50,000원/건 | 방문자 = 투자 관심층, 전환율 최고 |
| 2순위 | 교육 (투자 강의, 재테크) | 5,000~30,000원/건 | 방문자 관심사 매칭 |
| 제외 | 쇼핑, 뷰티 | — | 타겟 미스매치 |

---

## Step 3 — 광고 코드 삽입 (GitHub 소스 수정)

**삽입 위치:**

| 위치 | 효과 |
|------|------|
| 메인 대시보드 상단 배너 | 노출 최대 |
| 시황 분석 / 종목 리포트 본문 중간 | 콘텐츠 관련성 높음 |
| 사이드바 (데스크톱) | 지속 노출 |

**작업 방식:**
- Next.js 광고 컴포넌트 생성
- 각 페이지에 컴포넌트 삽입
- Cloudflare Pages 자동 배포 확인

> GitHub URL 확인 후 코드 작업 진행 예정
