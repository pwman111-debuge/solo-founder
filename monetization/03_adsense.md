# PHASE 4 — 애드센스 3차 신청 전략

> **선행 조건:** 커스텀 도메인 최소 1개월 이상 안정적 운영 후 진행

---

## 이전 낙방 원인 분석

| 추정 원인 | 해결책 |
|---------|--------|
| `pages.dev` 서브도메인 (신뢰도 낮음) | 커스텀 도메인으로 교체 (PHASE 1) |
| 필수 페이지 부재 | Privacy Policy, About, 연락처 추가 |
| 트래픽 부족 | 콘텐츠 확충 + Search Console 등록 |

---

## 재신청 전 체크리스트

### 필수 조건
- [ ] 커스텀 도메인 운영 1개월 이상
- [ ] Privacy Policy 페이지 추가
- [ ] About (소개) 페이지 추가
- [ ] 연락처 정보 노출 (이메일 또는 연락 양식)
- [ ] 콘텐츠 페이지 20개 이상 (고유 분석 콘텐츠)

### 권장 조건
- [ ] 월 방문자 3,000명 이상
- [ ] Google Search Console 색인 정상 등록
- [ ] 사이트 로딩 속도 최적화 (Core Web Vitals)

---

## Google Search Console 재등록 (PHASE 2)

1. [search.google.com/search-console](https://search.google.com/search-console) 접속
2. **속성 추가** → 커스텀 도메인 입력
3. Cloudflare DNS → TXT 레코드 추가 (소유권 인증)
4. 사이트맵 제출: `https://커스텀도메인/sitemap.xml`
5. URL 검사 → 색인 생성 요청

---

## 애드센스 신청 방법

1. [adsense.google.com](https://adsense.google.com) → 사이트 추가
2. 커스텀 도메인으로 신청
3. 애드센스 코드를 사이트 `<head>`에 삽입
4. 심사 기간: 2~4주 대기

---

## 수익 구조 (링크프라이스 + 애드센스 병행)

| 수익원 | 조건 | 예상 월 수익 |
|--------|------|------------|
| 링크프라이스 | 전환 건수에 따라 | 전환 10건 × 평균 1만원 = 10만원+ |
| 애드센스 | 월 방문자 1만 기준 | 5만~20만원 |
| **합계** | 두 가지 병행 | **15만~30만원+ (성장에 따라 상향)** |
