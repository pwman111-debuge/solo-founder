# genesis-report.com 유망종목 구독 서비스 전환 검토

작성일: 2026-05-01

---

## 황원장님 현황

- **본업**: 현직 내과 전문의 / 우리내과 의원 개원 (대구 중구)
- **운영 사이트**: genesis-report.com
- **목표**: 유망종목 메뉴를 유료 구독 서비스로 전환

---

## 핵심 결론

### 전자상거래업만으로는 불가

- 유망종목 정보를 구독료를 받고 불특정 다수에게 제공하면 **자본시장법 제101조상 유사투자자문업**에 해당
- 무등록 영업 시 형사처벌 위험
- 유튜브 유료회원제도 동일 규정 적용 (금융위원회 유권해석)

### 유사투자자문업 신고 필수

---

## 신고 요건

| 항목 | 내용 |
|------|------|
| 관할 | 금융감독원 신고 |
| 자본금 | 별도 요건 없음 |
| 사업자 형태 | 개인사업자 가능 |
| 결격사유 | 금융범죄 전과자 등 (의사/의료인 해당 없음) |
| 개원의 겸업 | 가능 (전공의 겸직 금지와 무관) |

---

## 신고 절차

```
1단계 → KIFIN 유사투자자문업 신고 사전교육 이수
2단계 → 개인사업자 신규 신고 또는 기존 사업자에 업종 추가
         (유사투자자문업 + 전자상거래업 병기)
3단계 → 금융감독원에 신고서 제출
4단계 → 수리 후 구독 서비스 런칭
```

---

## 사전교육 관련 (중요 — 미확인 사항 있음)

### 집합교육 (확실)
- 장소: 여의도 금융투자교육원
- 일정: 매월 셋째 목요일
- 시간: 8시간
- 비용: 약 33만원

### 온라인 교육 (현재 운영 여부 미확인)
- 코로나 기간(2020~2022): 온라인으로 대체 운영
- 2023년 이후: 집합교육 재개
- 현재 온라인 과정 병행 여부 → **KIFIN에 직접 확인 필요**

> ⚠️ "온라인으로 가능하다"는 이전 정보는 과거 기수 과정 기준으로 현재와 다를 수 있음

### KIFIN 문의처
- 전화: 02-2003-9000
- 사이트: www.kifin.or.kr
- 확인 질문: "유사투자자문업 신고 사전교육 현재 온라인 과정 개설 여부와 다음 일정"
